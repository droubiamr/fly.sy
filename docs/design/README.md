# Redesign: options and the chosen direction

Mockups from the October 2026 redesign. Each `.html` file is self-contained; open it in a browser. Nothing in this
folder is part of the site build.

**Chosen (1 Oct 2026): road signs, with the map on top** (`chosen/`). Passport green, the current logo and Readex
Pro. Each way into Syria is a green sign with a white inset rule. The arrows of the original idea are replaced by
what you travel in: a plane for a flight, a car for a crossing, both when you fly and then drive. Airlines appear as
white service tiles; restrictions such as "Syrians only" are small plates under the sign.

Kept in case the choice changes:
